# 密钥与数据保护

默认仅监听本机，不提供公网安全保证。DeepSeek Key经本机接口保存到服务端，Windows为DPAPI，配置GET只返回是否存在；其他平台仅文件权限。关闭设置抽屉清空未保存输入。任务恢复只保存编号与上下文，不保存Key。

生成报告会把问题、统计、部分事件和记忆发送至配置的云端模型，不上传原视频或权重。Embedding默认CPU本地，切换api后会发送文本到对应服务。本地Qdrant不等于整条链路不出网。

实际.env.local、agent-settings.json、SQLite/Qdrant、缓存、日志、报告、权重和视频必须忽略。发布前检查最终暂存与新提交，包括令牌、私钥、认证、实际本机Key精确匹配、个人路径；报告不回显值。截图不得展示配置敏感信息。

Key若暴露先撤销替换，再评估历史清理。勿在公开issue贴Key、数据库或漏洞细节。未配置独立安全邮箱，可使用GitHub可用的私密报告入口或维护者私密渠道。
