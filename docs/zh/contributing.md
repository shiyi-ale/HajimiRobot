# 参与开发

使用独立分支，说明用户问题、行为变化和验证。不得提交实际.env、数据库、日志、视频、权重或Key。模型清单仅保留相对路径、类别、校验摘要。

先阅读架构/API/验证。统计修改增加空洞、跨日、乱序、覆盖测试；归组不能增加行为时长。UI检查手机、键盘和中英语言。依赖同步锁文件，版本同步VERSION、包元数据与OpenAPI。

提交前运行verify.ps1和 `scripts/check_release.py --staged`。扫描只输出位置，不回显匹配值。项目维持当前许可状态，不擅自为代码、第三方依赖或素材追加授权。Frigate借鉴和固定提交在研究文档中说明，不使用其品牌标识。
