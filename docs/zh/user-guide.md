# 用户指南

## 活动回看
选择摄像头、日期、来源。首屏保留开始/停止、播放器、活动列表与时间线。模型、输入源、ROI和参数在设置抽屉，运行诊断默认收起。

活动卡片定位关联录像；彩色轨道保留原始行为片段，卡片按回看组展示。默认间隔10秒、最长1小时，确认断流和设备会话切换打断归组。整组跨度不等于行为时长。分钟放大可看短片段，方向键移动10秒。播放或手动标记保存已查看，新证据使旧标记失效。

录像轨道只表示可播放文件。观测轨道区分目标、空检测、跳过推理、失败、确认断流、未知和未来。无录像不代表无宠物。

## 行为报告
选择上下文，使用今日小结、七日比较或自定义问题。任务只显示真实排队/运行状态，同标签页切换页面或刷新可恢复。先看摘要与发现，再看观测局限和依据。

绿色条为当日观测占比，浅棕条为有效历史日平均。进食片段不等于投喂指令。依据抽屉展示统计ID、事件和录像，可跳到活动位置。支持Markdown与JSON导出。

历史按摄像头和来源分页，打开报告会恢复其真实日期/来源。中英切换不自动翻译保存的模型正文。

统计报告表示未调用模型或校验失败回退；语义降级仍可用SQLite证据。证据不足时不强行绘制趋势。合成案例不是实际宠物结论，报告不构成医学诊断。
