# NVR 事件时间线

打开 http://127.0.0.1:3000 的 NVR 页面。界面参考 Frigate Review 的按时间浏览和筛选思路：https://docs.frigate.video/configuration/review/ 。这是现有 Hajimi 服务上的独立实现。

- 桌面端：左侧播放器和时间线，右侧事件 / 录像列表；窄屏自动堆叠。
- 选择日期、摄像头、数据来源和行为类别。时间统一显示 Asia/Shanghai。
- 时间轴支持1、6、24小时视野；灰色轨道表示 ready 状态的录像，六条彩色轨道表示行为片段。
- 点击事件会定位关联录像的相对秒数。点击录像轨道定位该时间；左右方向键移动10秒，Home/End移动至当天边界。
- 播放时游标随进度更新。跨文件的录像需要选择其他片段，不会伪造连续录像。
- 未关联录像的事件显示“仅检测记录”，空白时间不代表没有宠物。
- 事件列表每页30条，避免原页面只显示前100条。录像按所选日期加载，包括跨日相交片段。
- 回看列表现按近邻活动归组，原始片段仍保留在彩色轨道；页面分别显示组跨度、有效检测、空检测和未观测时长。默认合并间隔10秒、最长1小时，支持已查看版本记录。
- 观测覆盖轨道区分空检测、未推理、确认断流、原因未知和尚未发生；新增1分钟、15分钟缩放。完整策略与数据库说明见 `Frigate-源码策略与落地.md`。
- 回看来源不修改摄像头采集配置；合成案例明确标识，并且没有伪造对应录像。
- 视频来源、GPU、ROI和运动调度参数保留在“视频来源、ROI与推理配置”折叠区；运行指标保留在下方。

## 当前数据演示

选择2026-10-18、本地视频，可点击已有坐姿事件回看实际视频；选择2026-10-17、合成案例，可浏览全天六类行为时间线。后者只用于演示，不能当作真实检测验收。

## API

`GET /api/v1/clips?camera_id=primary&source=local-video&day=2026-10-18`

day可选；指定后查询与该报告时区日期相交的录像，不受原最近200条限制。不指定时保留原有最近200条行为。非法日期返回422。

## 验证

类型检查、前端生产构建及30项Python测试通过。浏览器验证了真实录像加载、事件偏移定位、小时缩放、案例来源切换、行为筛选及无关联录像提示。当前没有实现Frigate的预览缩略视频、已审阅同步和跨录像文件无缝播放。
