# Agent 合成案例数据

本批是为系统演示生成的**合成案例**，不是 YOLO 对真实宠物的观测。真实视频检测记录和录像没有被替换。

## 数据范围与复现

- 报告案例日：2026-10-17；历史基线：2026-10-10 至 2026-10-16。
- 摄像头：primary；来源：test；设备：synthetic-case-generator-v1；模型标识：SYNTHETIC-CASE-V1-NOT-YOLO。
- 共 89,100 个合成检测帧。前七天每天 11,160 帧，案例日 10,980 帧。
- 每帧代表情境中明确设定的 5 秒观测区间；06:00–22:00 为假设观测窗口。
- 正常日覆盖率 64.58%，案例日覆盖率 63.54%，均按完整自然日计算。
- 10:10–10:20、18:40–18:50 有观测但无目标；14:00–14:30 没有观测；案例日另有 18:20–18:35 观测空洞。
- 前七天保持有小幅变化的进食、玩耍、坐姿和休息节律；案例日主动减少玩耍、增加休息，并缺少一段进食观测。
- 不生成虚假录像，不产生投喂硬件指令，不伪造真实推理性能。

```powershell
.venv/Scripts/python.exe services/intelligence/seed_cases.py --end-date 2026-10-17 --ingest
```

脚本先写出 JSONL，再通过真实批量检测 API 入库，逐日核对帧数、观测秒数和六类行为时长。确定性的设备/会话/帧 ID 允许重复执行，不会重复累计。

生成文件保存在 `.runtime/case-data/`：

- `frames.jsonl`：完整合成输入。
- `manifest.json`：生成规则、日期范围、每日预期指标及入库校验记录。
- `report-job.json`：生成报告的请求与任务 ID。
- `report.json`、`report-2026-10-17.md`：最终报告与可读导出。

打开 <http://127.0.0.1:3000> → Agent，选择 2026-10-17、主摄像头、**合成测试数据**。已保存报告中最新的 Agent 分析为本案例结果。可以展开事件、七天基线与语义记忆，或导出 JSON。
