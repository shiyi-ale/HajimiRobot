# YOLO26

This directory contains the YOLO26 cat behavior recognition notes currently used by HajimiRobot.

## Included

- `yolo26-cat-lightweight/`

## Core Classes

- `eating`
- `playing`
- `rest`
- `sitting`
- `stretching`
- `yawning`

## Usage

These classes are consumed by the Web-Console history reports, behavior timeline, and recognition logging pipeline.
