# YOLO26

这个目录保存 HajimiRobot 当前使用的 YOLO26 猫行为识别相关说明。

## 包含内容

- `yolo26-cat-lightweight/`

## 核心类别

- `eating`
- `playing`
- `rest`
- `sitting`
- `stretching`
- `yawning`

## 用途

这些类别被 Web-Console 的历史报告、行为时间轴和识别记录逻辑消费。
